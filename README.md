# Trenvo Media Links Page

A modern, responsive links page for **Trenvo Media**, built with **React** and **Tailwind CSS**.

The page is designed to act as a central hub for Trenvo Media's important links, social platforms, website, and WhatsApp contact.

## Features

* Responsive design for mobile, tablet, and desktop
* Modern card-based link layout
* Trenvo Media branding
* Responsive logo sizing
* Floating WhatsApp button
* Direct links to external platforms
* Background graphic elements
* Clean hover and interaction states
* Built with reusable React components

## Tech Stack

* React
* Tailwind CSS
* Vite

## Running Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Links Configuration

The page links are configured directly inside the project source.

Update the relevant link values before deploying to production.

Examples include:

* Trenvo Media website
* Social media profiles
* Portfolio or service links
* WhatsApp contact link

## WhatsApp Link

The floating WhatsApp button should use the standard WhatsApp URL format:

```text
https://wa.me/COUNTRYCODEPHONENUMBER
```

Example:

```text
https://wa.me/923001234567
```

Do not include spaces, brackets, `+`, or dashes in the phone number.
